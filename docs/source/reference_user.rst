User reference
==============

This is the user reference for the LinkBikeNet package. If you are looking for an introduction to LinkBikeNet, read the :doc:`getting_started` guide.

The standard way to import the LinkBikeNet package is via ``import linkbikenet as lbn``. The main ``linkbikenet()`` function below is then called via ``lbn.linkbikenet()``, see the :doc:`mwe`.
